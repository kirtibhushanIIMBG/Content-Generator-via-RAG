# langgraph whose checkpoint submodules sit elsewhere (and, because requirements.txt was unchanged

# crashed at `from src.graph.pipeline import ...` with an ImportError.

# These are the exact versions the ENTIRE test suite passed against, and they are a coherent set:
# langgraph 1.2.9 requires langchain-core >=1.4.7,<2, so an unpinned `langchain` pulling a 2.x
# core would fail to resolve on the cloud. Pin the whole orchestration + LLM-binding layer so the
# cloud reproduces the tested environment exactly. All pure-Python wheels — safe across
# Windows->Linux (fastembed/onnxruntime/qdrant are deliberately left unpinned below to avoid a
# platform-wheel mismatch). Bumping any of these means re-running tests/ first.
